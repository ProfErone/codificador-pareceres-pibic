# Codificador de Pareceres — PIBIC/UNOESC

Instrumento de codificação da pesquisa "Dimensões do desenvolvimento infantil nos pareceres descritivos: análise documental na pré-escola". Página única (`index.html`), sem servidor. Versão 1.0.1-piloto.

## Publicar no GitHub Pages
1. Crie um repositório e envie `index.html` e este `README.md`.
2. Em **Settings › Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O endereço fica `https://<usuário>.github.io/<repositório>/`.

## Onde ficam os dados
- **Só no navegador de quem codifica.** Nada vai para o GitHub: o repositório guarda apenas o programa.
- Limpar o navegador, usar aba anônima ou trocar de computador faz os pareceres sumirem daquele navegador. Use **Fazer backup** ao fim de cada sessão e guarde o arquivo.
- Para continuar em outro computador: **Fazer backup** no primeiro e **Importar** no segundo.

## Enviar os pareceres para a orientadora
- **Gerar ZIP final** baixa um ZIP com um JSON por parecer, o manifesto, as tabelas CSV e as fichas.
- Cada JSON é selado (SHA-256). O **Importar** do Codificador recusa arquivo alterado.
